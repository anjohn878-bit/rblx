# UI style notes

Add a section per style the user wants (from their reference screenshots). Record principles, not assets.

## default ("chunky arcade")
- Navy panels (#2f3a6b), saturated action colours (blue / gold / green / red).
- 3 px outline at 1080p everywhere, 14 px corners, 6 px blue-tinted shadow, 18% top lift.
- Bold rounded sans (GothamBold), white text with dark-navy stroke.
- Primary action bottom-centre, currency top-left, menus left-middle.
